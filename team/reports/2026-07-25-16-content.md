## 1. P0 — `complete_text` argv → stdin (최우선)

### 1.1 무엇을 바꿨나 (`generator.py:299-349`)

`claude -p <프롬프트>` 에서 프롬프트를 **인자에서 빼고 stdin 으로** 넘긴다. system 만 argv 에 남는다.

```python
# generator.py:317
def _claude_cli_text(user: str, system: str, model: str, *, timeout: int = 900) -> str:
    cmd = ["claude", "-p", "--append-system-prompt", system,
           "--output-format", "json", "--model", model]
    argv_chars = sum(len(a) for a in cmd) + len(cmd)
    if os.name == "nt" and argv_chars > _WIN_CMDLINE_LIMIT - _ARGV_SAFETY_MARGIN:
        raise RuntimeError(...)          # system 이 비대해지면 WinError 206 대신 명확한 메시지
    proc = subprocess.run(cmd, input=user, capture_output=True, text=True,
                          encoding="utf-8", timeout=timeout)
```
호출부 2곳이 이 함수를 쓴다 — `complete_text():944`(검수기 등 범용), `_via_claude_cli():1110`(초안 생성).
봉투 `is_error` 처리도 통일했다: 예전 `complete_text` 는 `{"is_error":true,"result":"Not logged in…"}` 를 **정상 결과처럼 반환**해 상위에서 엉뚱하게 깨졌다. 이제 둘 다 `RuntimeError` 로 올린다.

### 1.2 ⛔ stdin 보호(01-content `stdin=DEVNULL` 도입 취지)를 깨지 않았다

그 보호의 목적은 "**부모 stdin 을 상속시키지 않는다**"이다(콘솔 없는 Task Scheduler 에서 CLI 즉사).
`subprocess.run(input=...)` 은 stdin 을 **새 파이프로 열고**(상속 없음) 다 쓴 뒤 **닫는다** → 자식은 프롬프트를 읽고 즉시 EOF.
`DEVNULL` = "빈 입력 + 즉시 EOF", `PIPE+close` = "프롬프트 + 즉시 EOF". **상속이 없다는 점과 tty 대기 경로가 없다는 점이 동일**하다. 코드 주석 `generator.py:299-312` 에 근거를 남겼다.

## 2. P1 ⑤ — AI 티: 조치했으나 **효과 미달**(정직 보고)

### 2.1 원인 진단 — 피드백이 "어느 문장"인지 말해주지 않았다

`selfcheck_detail` 의 리듬 플래그(미러 구문·em 대시)는 **quote 가 빈 문자열**이었다.
`_rewrite_feedback` 은 quote 만 인용하므로, 모델이 받은 지시는 사실상 **"Cut this stock phrasing"** 한 줄 — 어디를 고쳐야 하는지 알 수 없었다. 어제 "2건 검출 → 재작성 → 2건 그대로"의 기계적 이유다.

### 2.2 조치 3가지

| # | 무엇 | 위치 |
|---|---|---|
| a | 리듬 플래그가 **문장 전체를 인용**한다(정규식 조각 아님, 미러 3개·대시 단락 2개) | `selfcheck_detail():818-834` |
| b | ai-tell 은 **왜 걸렸는지(note)까지** 피드백에 넣는다. 다른 kind 의 note 는 계속 숨긴다 | `_NOTE_VISIBLE_KINDS:727`, `_rewrite_feedback():734` |
| c | **재검사 후 남으면 한 번 더** 재작성. ⛔ 최대 2회, 그래도 안 줄면 중단·로그 | `_resolve_provider():110-145`, `_SELFCHECK_MAX_REWRITES:597` |

(b)의 근거: 리듬·클리셰 지적은 **형태**에 대한 것이라 토큰을 덧대 만족시킬 수 없다(고치려면 다시 써야 한다). 반대로 `volatile-figure`·`negative-claim` 의 note 는 "무엇을 붙이면 통과하는가"를 알려주는 셈이라 계속 숨긴다.

실제 피드백 출력(2회차):
```

still in the draft. Do not make another light edit: rewrite the affected passages from scratch, …
- Rewrite the quoted sentences themselves — deleting the flagged word and leaving the same sentence shape
  behind does not fix it. …
    what is wrong: the 'X, not Y' antithesis appears 4 times
    offending text: "It is a pricing question, not a feature question. ⟂ Not a benchmark, but a budget line.
                     ⟂ You are buying capacity, not convenience."          ← 구판 quote = ""
```
em 대시 플래그도 같다: `quote = "Hetzner — a German host — sells cheap boxes. ⟂ DigitalOcean — the US side — bundles managed pieces."`

토큰 누출 재확인(구 설계 유지): ai-tell 이외 kind 만 있는 초안의 피드백 1,667자에 탐지 토큰 12종(`as of`·`how we chose`·`selection criteria`·`our pick`·`we recommend`·`methodolog`·`checked on`·`figures absent from the cited material` 등) **등장 0종**.

### 4.1 변경 (`_finalize_sources():248-293` + 헬퍼 `197-245`)

구판은 페치 URL을 **전부 무조건** `sources` 에 넣었다. 신판은 **본문에 그 소스만의 근거가 나타날 때만** 넣는다.

## 1. ① R4 — 표식 지적은 **보내되 맥락을 붙인다**

### 무엇이 문제였나 (수정 전 실제 도달 문구)

`review_feedback` 은 `type/detail/fix` 만 읽는다 — `_apply_disclosure_policy` 가 붙인 `status="not_applicable"`·`reason`
은 **사본 쪽에만** 있어서, 재작성 모델은 표식 지적을 **평범한 수정 지시**로 받았다:

```
[before] … ; [legal] Article body contains no affiliate/ad disclosure. The site is AdSense-monetized …
          → Confirm the site-wide ad/affiliate disclosure … (지시로 읽힌다)
```

→ 광고도 제휴도 없는 사이트에서 이 지시를 따르면 **존재하지 않는 상업관계를 선언**하게 된다(=허위 진술).

### 수정 (orchestrator.py — `review_feedback` 및 전용 심볼)

```python
_NA_FEEDBACK_HEADER = (
    "ANNOTATED NOT-APPLICABLE by the review harness — read this before the objection(s) that follow: "
    "the ad/affiliate/sponsorship DISCLOSURE part of them does NOT apply. This site serves no advertising "
    "and this draft carries no affiliate or referral links, so do NOT add a disclosure, affiliate, "
    "sponsorship or 'we may earn a commission' line, and ignore any instruction below telling you to add "
    "one — writing such a line would itself be a false statement. This label is a lexical guess and is "
    "known to over-match: if an objection below ALSO states any OTHER defect, fix ONLY that other defect")
```

동작:
- 표식 지적을 **제외하지 않는다**(⛔ move 복귀 아님 — 88% 오부착이 다시 통째로 사라지는 결함이 재발한다).
- 표식 지적 묶음 **바로 앞**에 위 헤더를 놓고, 각 항목에 `[not_applicable · <type>]` 태그를 단다.
- 헤더가 "**아래의 추가 지시를 무시하라**"까지 명시한다 — 지적의 `fix` 가 대개 "Add a disclosure line…" 이라
  헤더가 그것을 명시적으로 무효화해야 한다.
- 매칭은 `(type, detail, fix)` 3필드 동일성으로만 한다(`_issue_key`) — **orchestrator 에서 어휘 재분류를 하지 않는다.**
  분류는 reviewer 소관이고 여기서는 그 결과(`issues_not_applicable`)만 읽는다.

### 수정 후 실제 도달 문구

```
[after] … ; ANNOTATED NOT-APPLICABLE by the review harness — read this before the objection(s) that follow:
        the ad/affiliate/sponsorship DISCLOSURE part of them does NOT apply. This site serves no advertising
        and this draft carries no affiliate or referral links, so do NOT add a disclosure, affiliate,
        sponsorship or 'we may earn a commission' line, and ignore any instruction below telling you to add
        one — writing such a line would itself be a false statement. … fix ONLY that other defect:
        [not_applicable · legal] Article body contains no affiliate/ad disclosure … → Confirm the site-wide …
```

표식 없는 판정에는 헤더가 붙지 않는다(불필요한 프롬프트 오염 방지 — `[9](b)`).

## 작업
- [ ] **`move` → `copy` 로 바꿔라.** 지적을 `issues` 에서 빼지 말고 **그대로 두고** `issues_not_applicable` 에 사본을 남긴다.
      그러면 (a)(b) 가 동시에 사라진다(수행자 자신이 제안한 방향, PM 채택).
- [ ] **`passed` 불리언 강제 캐스팅.** `reviewer.py:477` `data.setdefault('passed', False)` 는 LLM 이 문자열 `"false"` 를 내면
      그대로 두고, `orchestrator.py:252` 의 `if not rv.get('passed')` 에서 **truthy 로 평가돼 통과**된다.
      → 문자열·숫자·None 을 안전하게 bool 로 정규화하라(`"false"`·`"0"`·`""` 는 False). 이번 라운드로 생긴 버그는 아니나 **실재하는 통과 경로**다.
- [ ] **`_AD_CODE_RE` 한계를 문서화**하라. 고정 패턴 목록이라 GTM 컨테이너·서버사이드 삽입·목록 밖 신규 네트워크는 놓친다.
      fail-closed 는 "스캔 0파일"만 막고 **"스캔했으나 패턴을 놓침"은 못 막는다.** 코드 주석 + 보고서에 명시하고,
      실제 광고 게재 시 `config/content.yaml monetization.ads_live` 또는 `ADSENSE_MONETIZED=1` 로 **선언**하는 것이
      1차 수단임을 `/adsense-audit` 체크리스트에 못 박아라.

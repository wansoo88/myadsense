# /adsense-audit — 승인 준비도 · 정책 점검 SOP

## 언제 쓰나
- AdSense **신청 직전**, **거절 후 재신청 전**, 운영 중 **정기 정책 점검**.

## 가드레일 (먼저 — docs/RESEARCH.md F2·F3, 위반 시 계정 영구 정지)
- **무효 트래픽 금지**: 자기/지인 클릭, 봇, 클릭 교환, 유료 클릭 — 어떤 인위적 부풀리기도 금지. "테스트 클릭"도 금지.
- **Privacy Policy는 강제 필수**. 없으면 신청·운영 불가 판정.
- 절대 수치(RPM/CPC) 단정 금지 → 필요 시 사용자 AdSense 리포트로 검증.

## 절차

### 1. 필수 요건 점검 (Google 1차 기준, F1·F2)
- [ ] **18세 이상 + 사이트 HTML 편집 권한** 보유? (없으면 신청 불가)
- [ ] **Privacy Policy 페이지 존재 + 접근 가능?** 포함 항목 확인:
  - 데이터 수집·이용 공개 / 제3자(Google) 쿠키·광고 네트워크 고지 / 벤더 링크 / 맞춤광고 옵트아웃(Ads Settings · aboutads.info) / 개인정보보호법 준수.
- [ ] (권장·필수 아님, R2) About·Contact 페이지 — 신뢰 신호. 저비용이니 추가 권고하되 **거절 사유로 단정 금지.**
- [ ] **광고·제휴 고지 게이트 상태 확인 → §3.5** (승인 신청·광고 코드 삽입 직전 필수. 지금 OFF 인 것은 정상이나, 광고를 켜는 날 반드시 ON 이어야 한다.)

### 2. 콘텐츠 품질·권위 점검 (F1 — 글 수가 아니라 품질)
- [ ] 각 글이 **독창적**인가? (복제·스크래핑·AI 대량 양산·자동 번역 덤프 ❌)
- [ ] 검색 의도를 **실제로 충족**하는 깊이가 있는가? (얇은 글 다수보다 깊은 글)
- [ ] E-E-A-T 신호: 저자 정보·전문성·1차 경험·출처·최신성.
- [ ] 네비게이션·핵심 페이지 정상, 빈/공사중 페이지 없음.
- ⚠️ **"글 30~40개·1000단어" 같은 수치 기준은 강요하지 말 것**(R1, 공식 기준 없음). 다만 콘텐츠가 너무 빈약하면 "청중을 끌어들이는 충분한 양"이 안 된다고 안내.

### 3. 정책 위반 리스크 점검 (F3·F4)
- [ ] 금지 콘텐츠 없음(성인·폭력·저작권 침해·위험 행위 등).
- [ ] 클릭 유도 문구("광고를 클릭하세요") 없음.
- [ ] 무효 트래픽 이력/리스크 없음(과거 자기 클릭·유료 클릭·봇 유입).
- [ ] 유료/통제된 트래픽을 쓴다면 **referrerAdCreative(RAC) 준수**(2025-11-01, RSoC 한정, F4) — 기본은 유료 트래픽 회피 권고.

### 3.5 🔔 광고 게재 전환 시점 — 광고·제휴 고지 게이트 부활 확인 (**잊으면 안 되는 항목**)

검수기(`engine/content/reviewer.py`)의 **"광고·제휴 고지 없음"** 지적은 **실제 수익화 상태에 연동**돼 있다(ORDER 2026-07-24-12).
지금은 사이트에 광고 코드도 제휴 링크도 없어서 **꺼져 있고, 그게 맞다** — 없는 상업관계를 고지하면 그 고지 자체가 허위 진술이다.
**광고를 켜는 순간 이 요구는 다시 켜져야 한다.** 판정은 추측이 아니라 관측으로 이뤄진다:
① 렌더 템플릿(`renderer.py`·`site_builder.py`)·빌드 산출물(`dist/site/**/*.html`)의 광고 네트워크 코드,
② 초안 자체의 제휴/추천 링크, ③ 명시 선언(`config/content.yaml` `monetization.ads_live|affiliate_links: true` 또는 `ADSENSE_MONETIZED=1`).
**선언은 켜는 방향으로만 동작한다 — 요구를 끄는 스위치는 없다.**

**상태 확인 (신청 전·광고 삽입 후 반드시 실행, 리포 루트에서)**
```powershell
python -c "import sys,json; sys.path.insert(0,'engine'); from content import reviewer; print(json.dumps(reviewer.monetization_state(), ensure_ascii=False, indent=2))"
```
- 광고 코드를 넣기 전: `"monetized": false` 가 정상.
- **광고 코드를 넣은 뒤: `"monetized": true` 여야 한다.** false 로 남아 있으면 게이트가 꺼진 채 발행된다 → 아래 순서로 즉시 복구.

**광고를 켜는 날 체크리스트 (전부 완료 전에는 광고 코드 배포 금지)**
- [ ] 1) **글 페이지에 고지가 실제로 렌더되는가.** 현재 광고·제휴 고지 문구는 `/privacy/`·`/about/` 에만 있고
      **글 템플릿에는 없다**(`site_builder.py:222-223`, `:260-263` — 2026-07-24 실측). 광고를 켜면 기사 본문 상단/하단에
      고지 1줄이 보이도록 렌더러를 수정해야 한다. ⚠️ `renderer.py`·`site_builder.py` 는 **OPS 소유** → REVIEW 는 요구만 하고 직접 고치지 않는다.
- [ ] 2) **먼저 선언하고, 그 다음 관측을 확인한다(순서 중요).** `config/content.yaml` 에
      `monetization: {ads_live: true}` 를 넣거나 `ADSENSE_MONETIZED=1` 을 설정한 **뒤** 위 명령으로 `monetized: true` 를 확인.
      ⚠️ **자동 탐지를 1차 수단으로 삼지 말 것** — 아래 "탐지의 한계" 참조. 선언이 1차, 탐지는 백스톱이다.
- [ ] 3) 고지 문구가 **사실과 일치**하는가. 제휴 링크가 없으면 "제휴 링크로 수수료를 받는다"고 쓰지 말 것(반대 방향의 허위 고지).
- [ ] 4) 승인 신청 전 `/privacy/` 의 광고 관련 서술이 **현재 상태와 일치**하는지 점검(F2 항목과 별개 — 정확성 문제).
- [ ] 5) 광고 켠 뒤 **첫 검수 1건**의 `dist/review/<slug>.json` 에서 `"monetization": {"monetized": true}` 와
      고지 항목 부활을 눈으로 확인.

**⚠️ 탐지의 한계 — 스캔은 "광고 없음"을 증명하지 못한다 (ORDER 2026-07-25-21 ③)**

`reviewer._AD_CODE_RE` 는 **고정 패턴 목록**(adsbygoogle·googlesyndication·doubleclick·ezoic·mediavine 등)이다. 따라서:
- **GTM/태그 매니저 컨테이너**로 주입되는 광고 — HTML 에는 컨테이너 한 줄뿐이라 **안 잡힌다**.
- **서버사이드·엣지 삽입**(nginx `sub_filter`, CDN worker) — 빌드 산출물을 읽는 스캔의 사각지대.
- 목록 밖 **신규·소규모 네트워크**, 난독화·동적 조립된 스크립트 URL.

fail-closed 설계(`templates=0` → `known=false`)가 막는 것은 **"스캔을 못 했다"뿐**이다.
**"스캔했는데 패턴을 놓쳤다"는 못 막는다** — 그 경우 관측은 자신 있게 `monetized:false` 라고 답하고,
고지 요구는 꺼진 채로 남는다. 그러므로:

> 요약: **이 항목은 삭제된 적이 없다. 조건이 붙었을 뿐이다.** 조건을 켜는 **1차 수단은 사람의 선언**
> (`monetization.ads_live: true` / `ADSENSE_MONETIZED=1`)이고, 자동 탐지는 **선언을 잊었을 때를 위한 백스톱**이다.
> 위 1)번(글 페이지 고지 렌더)도 사람·OPS 몫이다. "광고를 켜면 알아서 켜진다"에 기대지 말 것.

### 4. 거절 사유 매핑 (거절 후)
거절 메시지를 위 1~3 항목에 매핑 → 가장 흔한 실제 사유:
- "콘텐츠 가치 낮음/불충분" → §2 품질·깊이 보강.
- "정책 위반" → §3 항목별 제거.
- (Privacy Policy 누락) → §1 즉시 추가.
**14일 후 재신청** 전 audit 재실행.

```
[adsense-audit] 결과: 신청 가능 / 보완 필요 / 신청 불가
■ 필수: Privacy Policy [O/X], HTML권한 [O/X], 18+ [O/X]
■ 품질: 독창성 [O/△/X], 깊이 [O/△/X], E-E-A-T [O/△/X]
■ 정책: 금지콘텐츠 [없음/발견], 무효트래픽 리스크 [낮음/높음]
■ 수익화·고지(§3.5): 광고게재 [예/아니오], 고지 게이트 monetized [true/false], 일치 [O/X]
■ 차단 사유(있으면): ...
■ 다음 액션: 1) ... 2) ...
```
필요 시 결과를 **로컬 HTML 보고서**로 저장(Artifact 금지 — CLAUDE.md 정책).

무효 트래픽 유발 제안, 반증된 통념(글 수·About/Contact 필수) 강요, 블로그 절대 수치 단정.
